
# Ranking FEDO OE2010

Sistema compatible con:

- OE2010
- PDFs provisionales
- GitHub Pages
- Google Sheets

## Funciones

- subir PDFs
- parser específico OE2010
- ranking automático
- múltiples carreras
- categorías automáticas
- export CSV
- Google Sheets online

## Configuración

1. Crear Google Sheet
2. Crear pestaña:
Resultados

3. Abrir Apps Script
4. Pegar apps_script.gs
5. Deploy -> Web App
6. Permisos -> Anyone

7. Copiar URL

8. Pegar URL en:

app.js

const API_URL = "TU_URL";

## Publicar GitHub

Settings -> Pages -> Deploy from branch -> main
